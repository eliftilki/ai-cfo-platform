# MVP Scope

Included in the current MVP:

- Supabase-backed auth and company context checks
- Dashboard overview endpoint
- AI CFO ask flow
- Intent routing for cashflow, marketing, general finance and action-priority questions
- Cashflow, marketing and risk analytics
- Natural-language and structured simulation support
- Next.js web app with auth, dashboard and AI CFO chat screens

Not included yet:

- Production-grade SQL migrations
- Full admin UI
- Fine-grained internal service authentication
- Automated OpenAPI-to-TypeScript client generation
